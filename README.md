# DevOps Projects

Small Bash tools for common Linux system administration and DevOps tasks.

## Projects

- [Server Performance Stats](server-performance-stats/README.md) — displays Linux system and performance metrics. Based on the [roadmap.sh Server Stats project](https://roadmap.sh/projects/server-stats).
- [Log Archive Tool](log-archive-tool/README.md) — creates timestamped compressed archives of log directories. Based on the [roadmap.sh Log Archive Tool project](https://roadmap.sh/projects/log-archive-tool).
- [Nginx Log Analyser](nginx-log-analyser/README.md) — summarizes the most frequent IP addresses, request paths, response status codes, and user agents in an Nginx access log. Based on the [roadmap.sh Nginx Log Analyser](https://roadmap.sh/projects/nginx-log-analyser).
